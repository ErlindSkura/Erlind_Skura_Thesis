\section*{A.1 \quad Dataset Characterisation and Calibration}

The following module parses the LabelMe annotations, recovers the physical pixel
size from each micrograph's burned-in scale bar, and produces the descriptive
statistics and figures reported in Chapter~\ref{ch:methodology}. Object area is
computed analytically from the polygon vertices rather than from a rasterised mask,
for the reason given in Section~\ref{sec:parsing}.

\begin{lstlisting}[language=Python, caption={Polygon area and physical calibration (\texttt{code/dataset\_stats.py})}]
# The 11 original micrographs, keyed by specimen and magnification. The
# suffix encodes magnification, not a repeat: -1 is 500x, -2 is 1kx,
# -3/-4 is 3kx.
IMAGES = {
    "Z2-1": ("Z2", 500), "Z2-2": ("Z2", 1000), "Z2-3": ("Z2", 3000),
    "Z4-2": ("Z4", 1000), "Z4-3": ("Z4", 3000),
    "Z5-1": ("Z5", 500), "Z5-2": ("Z5", 1000), "Z5-3": ("Z5", 3000),
    "Z6-1": ("Z6", 500), "Z6-2": ("Z6", 1000), "Z6-4": ("Z6", 3000),
}

# Calibrated from the burned-in scale bars: the field width is 284.4 um
# at 1000x and scales inversely with magnification, over 1024 px.
NM_PER_PX = {500: 555.6, 1000: 277.8, 3000: 92.6}

BANNER_H = 32  # burned-in Zeiss info bar at the bottom of every micrograph


def polygon_area(points):
    """Shoelace area of a closed polygon, in px^2."""
    n = len(points)
    return abs(
        sum(
            points[i][0] * points[(i + 1) % n][1]
            - points[(i + 1) % n][0] * points[i][1]
            for i in range(n)
        )
    ) / 2.0


def collect():
    """Per-image bead areas, equivalent diameters and physical sizes."""
    out = {}
    for name, (specimen, mag) in IMAGES.items():
        ann = json.loads((DATA / "Labels" / f"{name}.json").read_text())
        areas_px = [polygon_area(s["points"]) for s in ann["shapes"]]
        diam_px = [2 * math.sqrt(a / math.pi) for a in areas_px]
        scale = NM_PER_PX[mag] / 1000.0  # um per px
        out[name] = {
            "specimen": specimen,
            "mag": mag,
            "n": len(areas_px),
            "diam_px": np.array(diam_px),
            "diam_um": np.array(diam_px) * scale,
            "area_um2": np.array(areas_px) * scale**2,
        }
    return out
\end{lstlisting}

\section*{A.2 \quad Verification of the Supplied Augmentations}

The check reported in Section~\ref{sec:supplied_aug}, confirming that the polygons of
the pre-computed augmented copies remain correctly registered to their transformed
images. The copies are correct but are not independent samples, and are therefore
excluded from the analysis.

\begin{lstlisting}[language=Python, caption={Overlaying annotations on augmented copies}]
for name in ["Z2-1", "Z2-1_shift-150-0", "Z2-1_stretch-h-0.2", "Z2-1_flip-h"]:
    im = Image.open(f"Images/{name}.jpg").convert("RGB")
    ann = json.loads(open(f"Labels/{name}.json").read())
    draw = ImageDraw.Draw(im)
    for s in ann["shapes"]:
        draw.line(
            [tuple(p) for p in s["points"]] + [tuple(s["points"][0])],
            fill=(255, 0, 0), width=3,
        )
    im.save(f"check_{name}.png")
\end{lstlisting}
